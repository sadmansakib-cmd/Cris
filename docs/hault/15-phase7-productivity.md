# Phase 7 — Productivity

Landed plugins with real state via `ctx.kv`:

- `hault.tasks` — GTD lists with statuses (`inbox|next|waiting|done`).
- `hault.notes` — markdown with `[[wikilink]]` extraction and derived backlinks.
- `hault.calendar` — events, reminders, ICS export.
- `hault.pomodoro` — session log with today-focus/total stats.
- `hault.kanban` — boards / columns / cards with move ordering.
- `hault.habits` — daily/weekly logs with streak calculation.
- `hault.goals` — OKRs with progress rollup from key results.
- `hault.contacts` — local contacts plus Google People sync (`net.fetch` + OAuth-gated).

Web: `Productivity` tabbed page wired into the sidebar.
